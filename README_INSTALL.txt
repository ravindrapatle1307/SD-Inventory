SDMatchlessGift V9 - iPhone PWA

Upload these five files to the root of your existing GitHub Pages repository, replacing the older files:
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png

Then open your GitHub Pages HTTPS address in Safari on iPhone.
Tap Share > Add to Home Screen > Open as Web App > Add.

Your working records are stored locally on the iPhone using IndexedDB.
Use Backup regularly and save the JSON backup to Files, iCloud Drive, or Google Drive.
